A tiny Node 22 program that prints one original one-line joke — a single sentence of 114 characters — for make.fun's "The One-Line Laugh" bounty. The joke lives in `joke.txt` as plain text, and `main.ts` prints it, enforcing the competition's rule (one sentence, at most 200 characters) at run time.

> I asked my AI agent to write me a one-line joke, and it billed me for the laugh and kept the punchline for itself.

## Run it

```sh
node main.ts
```
